# Локализация


![Локализация](images/p172-01.jpg)

![Локализация](images/p172-02.jpg)

Предусматривает механизм для перевода элементов интерфейса Конструктора на другой язык.


Для настройки Локализации необходимо:

1. добавить нужный язык в Список языков;
2. добавить переводы используемых слов/фраз в Словарь.


Для переключение языка необходимо:

1. нажать на меню Профиля (иконка человечка с правом верхнем углу);
2. выбрать нужный язык из Combobox "Язык";

2.


3. обновить страницу в браузере (нажать кнопку F5).

Редактирование слов/фраз
1. перейти на страницу "Словарь" (CORE Локализация Словарь);
2. все действия производятся в гриде "Список слов/фраз";
3. выбрать слово/фразу для редактирования;


4. нажать кнопку "Редактировать значение" и внести необходимые изменения; Доступные поля для заполнения:

5. нажать кнопку "Сохранить".


Удаление слов/фраз
1. перейти на страницу "Словарь" (CORE Локализация Словарь);
2. все действия производятся в гриде "Список слов/фраз";
3. выбрать слово/фразу для удаления;
4. нажать кнопку "Удалить" и подтвердить удаление.


Добавление перевода слова/фразы

1. перейти на страницу "Словарь" (CORE Локализация Словарь);
2. выбрать слово/фразу из грида "Список слов/фраз";
3. дальнейшие действия производятся в гриде "Перевод";
4. нажать кнопку "Добавить";


5. заполнить доступные поля;


Доступные поля для заполнения:

Наименование поля Тип данных Комментарии

Язык Выбор из списка Обязательно для заполнения.

Перевод Текст Обязательно для заполнения.

6. нажать кнопку "Сохранить".


> **Обратите внимание!**
> Если для слова/фразы отсутствует перевод на язык, который выбран Пользователем в меню Профиль, то в
> интерфейсе будет отображен перевод на язык по умолчанию.


Редактирование перевода
1. перейти на страницу "Словарь" (CORE Локализация Словарь);
2. выбрать слово/фразу и перевод для редактирования;
3. все действия производятся в гриде "Перевод";


4. нажать кнопку "Редактировать значение" и внести необходимые изменения;


Доступные поля для заполнения:

Наименование поля Тип данных Комментарии

Перевод Текст Обязательно для заполнения.

5. нажать кнопку "Сохранить".


Удаление перевода
1. перейти на страницу "Словарь" (CORE Локализация Словарь);
2. выбрать слово/фразу и перевод для редактирования;
3. все действия производятся в гриде "Перевод";
4. выбрать перевод для удаления;
5. нажать кнопку "Удалить" и подтвердить удаление.

3. заполнить доступные поля;

> Языком по умолчанию может быть выбран только один язык.


При создании языка по умолчанию ко всем словам/фразам из Списка слов/фраз будут автоматически
сгенерированы переводы на указанный язык со значением: ##Need to translate##

1.

1. перейти на страницу "Список языков" (CORE Локализация Список языков);

3. нажать кнопку "Редактировать значение" и внести необходимые изменения; Доступные поля для заполнения:

Удаление языка
1. перейти на страницу "Список языков" (CORE Локализация Список языков);
2. выбрать язык для удаления;
3. нажать кнопку "Удалить" и подтвердить удаление.


> **Обратите внимание!**
> При удалении языка из Словаря будут автоматически удалены все переводы на данный язык.
