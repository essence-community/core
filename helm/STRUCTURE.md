# Структура Essence Helm Chart

```
helm/
├── Chart.yaml                 # Основная информация о chart
├── values.yaml               # Значения по умолчанию
├── values-production.yaml    # Значения для продакшена
├── values-development.yaml   # Значения для разработки
├── .helmignore              # Файлы для исключения из package
├── Chart.lock               # Зависимости chart (если есть)
├── README.md                # Документация по использованию
├── INSTALL.md               # Инструкции по установке
├── STRUCTURE.md             # Этот файл
├── deploy.sh                # Скрипт для быстрого развертывания
└── templates/               # Шаблоны Kubernetes ресурсов
    ├── namespace.yaml       # Namespace
    ├── rbac.yaml           # RBAC ресурсы (ServiceAccount, ClusterRole, RoleBinding)
    ├── secrets.yaml        # Секреты
    ├── storage.yaml        # PersistentVolume и PersistentVolumeClaim
    ├── database.yaml       # База данных PostgreSQL
    ├── backend.yaml        # Backend приложение
    ├── frontend.yaml       # Frontend приложение
    ├── ingress.yaml        # Ingress для внешнего доступа
    ├── NOTES.txt           # Информация после установки
    └── tests/              # Тесты
        └── test-connection.yaml
```

## Описание файлов

### Основные файлы

-   **Chart.yaml** - Метаданные chart'а (версия, описание, зависимости)
-   **values.yaml** - Конфигурация по умолчанию для всех компонентов
-   **values-production.yaml** - Оптимизированная конфигурация для продакшена
-   **values-development.yaml** - Упрощенная конфигурация для разработки

### Шаблоны (templates/)

-   **namespace.yaml** - Создание namespace для приложения
-   **rbac.yaml** - Настройка прав доступа (ServiceAccount, ClusterRole, RoleBinding)
-   **secrets.yaml** - Секреты для базы данных и приложения
-   **storage.yaml** - Настройка постоянного хранилища (PV/PVC)
-   **database.yaml** - Развертывание PostgreSQL базы данных
-   **backend.yaml** - Развертывание backend приложения
-   **frontend.yaml** - Развертывание frontend приложения
-   **ingress.yaml** - Настройка внешнего доступа через Ingress
-   **NOTES.txt** - Информация, отображаемая после успешной установки

### Тесты (templates/tests/)

-   **test-connection.yaml** - Тест подключения к сервисам

### Вспомогательные файлы

-   **deploy.sh** - Скрипт для автоматизации развертывания
-   **README.md** - Подробная документация по использованию
-   **INSTALL.md** - Пошаговые инструкции по установке
-   **.helmignore** - Список файлов для исключения из package

## Компоненты приложения

### 1. База данных (PostgreSQL)

-   Отдельный deployment и service
-   Постоянное хранилище для данных
-   Настраиваемые ресурсы и параметры

### 2. Backend приложение

-   Масштабируемый deployment
-   Health checks (liveness, readiness, startup probes)
-   Постоянное хранилище для модулей и конфигурации
-   RBAC настройки

### 3. Frontend приложение

-   Масштабируемый deployment
-   Health checks
-   Постоянное хранилище для модулей
-   Внешний доступ через LoadBalancer или Ingress

### 4. Сетевая настройка

-   Внутренние сервисы для связи компонентов
-   Внешний доступ через LoadBalancer или Ingress
-   Настраиваемые порты и типы сервисов

### 5. Хранилище

-   Три типа постоянного хранилища:
    -   Модульное хранилище (5-10Gi)
    -   Конфигурационное хранилище (200Mi-1Gi)
    -   Хранилище базы данных (5-20Gi)
-   Временное хранилище для кэша и логов

## Конфигурируемые параметры

### Глобальные настройки

-   Namespace
-   Docker registry
-   Image pull policy

### Компоненты

-   Включение/отключение компонентов
-   Количество реплик
-   Образы и теги
-   Ресурсы (CPU, Memory)
-   Health check параметры

### Сеть

-   Типы сервисов (ClusterIP, LoadBalancer)
-   Ingress настройки
-   TLS конфигурация

### Хранилище

-   Размеры томов
-   Storage classes
-   Пути для hostPath

### Безопасность

-   Секреты
-   RBAC настройки
-   Service accounts

## Преимущества использования Helm

1. **Простота развертывания** - Один команда для установки всего приложения
2. **Конфигурируемость** - Легкая настройка под разные окружения
3. **Версионирование** - Контроль версий конфигурации
4. **Повторяемость** - Идентичные развертывания в разных средах
5. **Управление зависимостями** - Автоматическое создание всех необходимых ресурсов
6. **Обновления** - Простое обновление приложения
7. **Откат** - Возможность отката к предыдущей версии
8. **Тестирование** - Встроенные тесты для проверки работоспособности
